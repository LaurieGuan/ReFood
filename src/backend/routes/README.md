# Routes — Developer 1

Flask blueprints and HTTP handlers. Validate request payloads with `schemas/`, call services and repositories, serialize Pydantic responses with `model_dump(mode='json')`. Never call grocery/vision providers directly inside routes. Planned `scans.py`, `pantry.py`, `recipes.py`, `prices.py` and optionally `marketplace.py`.
